白天看到微信官方支持 openclaw 🦞 插件的文章，晚上我的微信就支持了这个功能。
下面介绍下如何操作：

1. 确定是否有资格

打开微信`我` - `设置` - `插件`。如果显示有微信Clawbot那么恭喜你已经可以使用了。

![](https://static.xbaby.xyz/workspace-images%2F%E5%BE%AE%E4%BF%A1%E5%9B%BE%E7%89%87_20260323010532_36_1530.png)

点“详情” 它会显示安装插件的指令

![](https://static.xbaby.xyz/workspace-images%2F%E5%BE%AE%E4%BF%A1%E5%9B%BE%E7%89%87_20260323010532_37_1530.png)

2. 安装插件

如果你已经安装好 openclaw，那么直接打开龙虾宿主的服务器终端。输入以下代码：
```
 npx -y @tencent-weixin/openclaw-weixin-cli@latest install
```
回车之后等待一会就安装好了。最后它显示一个二维码，使用手机扫一下。如果成功的话 openclaw gateway 就会自动重启。

![](https://static.xbaby.xyz/workspace-images%2FScreenShot_2026-03-23_010126_640.png)

3. 体验
网关重启后，微信上就会多出来一个叫 `微信ClawBot` 的 bot。点击进入聊天，这样就可以跟 openclaw 对话啦。

![](https://static.xbaby.xyz/workspace-images%2F%E5%BE%AE%E4%BF%A1%E5%9B%BE%E7%89%87_20260323010533_38_1530.png)

4. 总结
这次龙虾的火爆，让微信也算是破了戒。最终还是支持了官方插件。而且整个过程还是非常丝滑的，没有碰到任何的坑。如果大家觉得这个文章有用请点点关注跟推荐，谢谢。
