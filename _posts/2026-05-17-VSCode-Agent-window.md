# VS Code 迎来史诗级更新：全新 Agents 窗口发布，“Prompt 优先”的 AI 生产力爆炸了！

在 AI 辅助编程的时代，你是否也有过这样的烦恼：
在传统的代码编辑器里和 AI 聊天，对话框总是被挤在窄窄的侧边栏；想让 AI 帮我多跑几个任务，它一会儿改这个文件，一会儿动那个文件，整个工作区被搞得乱七八糟，审查代码像是在做“大家来找茬”。

VS Code 官方敏锐地察觉到了这个痛点。在最近的更新中，VS Code 带来了一个重量级功能——**Agents 窗口（预览版）**。它打破了传统的“代码优先”界面，专门为“智能体优先”（Agent-first）的工作流打造了一个独立的操作系统。

今天，我们就来深度拆解一下这个全新的 Agents 窗口，看看它如何彻底改变我们的结对编程体验。

---

## 一、 “代码优先” vs “Prompt 优先”：两种工作流的无缝切换

VS Code 并不是要用 AI 窗口取代编辑器，而是为开发者提供了两套可以自由切换的“双轨制”界面：

* **编辑器窗口（Code-first）：** 传统的 VS Code 主窗口。当你正在逐行敲代码，需要 AI 在旁边提供行内补全、解释代码或辅助调试时，这依然是最佳选择。
* **Agents 窗口（Agent-first）：** 全新的独立窗口。当你需要扮演“架构师”或“Owner”的角色，通过编写 Prompt 来指挥 AI 智能体去跨文件修改、跑自动化测试、甚至重构整个模块时，这个窗口就是你的总指挥部。

最硬核的是，**这两个窗口共享完全相同的会话状态、配置和快捷键**。你可以随时在主窗口写累了，一键切到 Agents 窗口“放海鸥”让 AI 自己去干活。

---

## 二、 Agents 窗口的核心空间布局

打开 Agents 窗口后，你会发现整个 UI 布局完全是围绕“人机协作”来重新设计的：

| 核心区域 | 功能说明 | 核心亮点 |
| --- | --- | --- |
| **会话列表 (左侧)** | 管理所有工作区的智能体对话（Sessions） | 支持按工作区分组、右键重命名、置顶或标记完成。 |
| **自定义面板 (左下)** | 一站式管理智能体自定义配置 | 完美定制智能体在当前项目或全局环境下的行为偏好。 |
| **中央聊天区 (中间)** | 与智能体互动的核心地带 | 宽敞的 Prompt 交互空间，告别侧边栏的局促感。 |
| **变更面板 (右侧)** | 实时审查代码变更（Artifacts）和文件树 | 智能体改了什么一目了然，不需要去翻乱本地 Git。 |

---

## 三、 亮点速览：这次更新凭什么让人兴奋？

### 1. 梦幻联动：本地 Claude 智能体加入战场！

这是本次更新中最让我惊喜的地方。当你在本地的文件夹（Folder）中开启一个新会话时，你不仅可以选择 **Copilot CLI**，还可以直接选择启动 **Claude 智能体**（对，就是最近在 AI 圈大火的 Claude Code 生态的深度集成）！
如果本地算力或上下文不够用了，你还可以使用 **"Continue In"** 功能，一键把当前的对话无缝“交棒”给云端的 Copilot Cloud 智能体继续跑。

### 2. 套娃神器：防污染的“子会话”（Sub-sessions）

我们在给 AI 下复杂指令时，AI 经常会“跑偏”或者被之前的上下文误导。
Agents 窗口引入了类似浏览器标签页的**子会话**功能。在主任务运行期间，你可以点击 `+` 号开一个子标签页去探索新思路，由于上下文相互隔离，你完全不用担心新探索会污染主会话的记忆。

### 3. 行内评论：像 Review 同事代码一样调教 AI

AI 改完代码后，你可以在右侧的 **Changes（变更）** 标签页中打开 Diff 视图。
最酷的是，你可以**直接在差异视图的代码行上发表评论**！比如在第 15 行写一句：*“这里不要用 for 循环，改成 map 试试。”* 智能体会精准识别你的行内评论，并对该行代码进行二次迭代。

> **💡 个人体验：** 这种交互感，简直就像在 GitHub 上给一个刚入职的实习生提 PR Review 意见，极其舒适。

## 四、 强大的“双重记忆系统”，AI 越来越懂你

为了让智能体不变成“转头就忘”的鱼，VS Code 这次配置了极其硬核的记忆系统：

```
💡 VS Code 智能体记忆矩阵
├── 本地记忆系统 (Memory Tool - 数据安全保存在本地)
│   ├── 用户记忆 (/memories/) ── 跨所有项目持久化 (新会话自动加载前200行)
│   ├── 仓库记忆 (/memories/repo/) ── 针对当前项目，跨对话持久化
│   └── 会话记忆 (/memories/session/) ── 单次对话限定，随擦随走
└── 云端记忆系统 (Copilot Memory)
    └── 托管在 GitHub 云端，跨整个 GitHub Copilot 生态（包含 Web 端、CLI 等）共享

```

有了这套系统，你可以把项目的编码规范、常用组件库的坑、甚至你个人的口癖和代码风格写进记忆里，AI 越用会越顺手。
