# 垃圾佬上线：HP ProDesk 600G3 Mini —— OpenClaw 的新窝

最近，我的机柜里迎来了一位性价比极高的新成员。虽然是个二手的“老家伙”，但它的表现却让家里的那台 Gen8 老大哥感到汗颜。

## 1. 为什么要“另起炉灶”？

之前我的 **OpenClaw** 一直跑在 HPE Gen8 的虚拟机里。Gen8 虽然经典，但面对现代的 AI Agent 任务，其 CPU 架构和资源分配已经有些捉襟见肘。尤其是在处理一些**长任务**时，由于内存压榨和 CPU 调度问题，进程经常直接被系统 **Kill** 掉，导致任务频繁暂停。

为了给 OpenClaw 找个安稳的家，我决定物色一台高性价比的低功耗物理小主机。

## 2. 捡漏经历：150 块的快乐

在海鲜市场上，我以 **150 元**的价格斩获了这台 **HP ProDesk 600G3 Mini** 准系统。作为垃圾佬，这台机器的规格简直是完美的“执行节点”：

### 核心硬件规格一览

| 组件 | 详细参数 | 极客点评 |
| :--- | :--- | :--- |
| **主板芯片组** | **Intel Q270** | 商用级芯片组，支持 vPro 远程管理，稳定性极佳 |
| **CPU 插槽** | **LGA 1151** | 原生支持 Intel 第 6 代 (Skylake) 和第 7 代 (Kaby Lake) |
| **内存支持** | **DDR4 2133/2400** | 双插槽，最高支持 32GB，彻底告别 Gen8 昂贵的 DDR3 内存 |
| **硬盘扩展** | **NVMe M.2 + 2.5寸 SATA** | 支持双硬盘，M.2 走的是 PCIe 3.0 x4 全速通道 |

我自己配上了闲置的内存和硬盘，瞬间点亮，运行起来“嘎嘎香”！

## 3. 性能与功耗：物理机的压制力

换上这台 600G3 物理机后，OpenClaw 任务流畅度有了质的提升。最让我惊喜的是它的**功耗表现**，这对于一台 7x24 小时开机的边缘计算节点来说至关重要：

* **待机功耗：仅 5W**（几乎可以忽略不计的电费，甚至比某些路由器还省电）。
* **50% CPU 负载：约 13W**（运行 OpenClaw 任务时的平均功耗）。
* **稳定性：** 物理机直跑，彻底解决了虚拟机下资源竞争导致进程被 Kill 的玄学问题，长任务跑得稳如老狗。

## 4. 未来升级计划：27 元的性能飞跃

目前的 CPU 是 **Celeron G3930**，虽然现在跑 OpenClaw 任务已经顺滑多了，但作为一名合格的垃圾佬，升级是必须的。

我已经看好了下一阶段的灵魂配件：**Intel Core i3-6100T**。

* **令人发指的价格：只要 27 元！**（是的，你没看错，两杯奶茶钱换来 4 线程的质变，嘎嘎香）。
* **核心提升：** 从 2C2T 升级到 **2C4T**（增加超线程支持）。
* **性能增幅：** 预计综合性能能提高 **30% - 50%**。
* **低功耗优势：** T 系列处理器 TDP 仅 35W，静音、凉快、强劲。
